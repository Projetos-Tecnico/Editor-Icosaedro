# Editor-Icosaedro

Aplicação Windows Forms em C# (.NET Framework 4.7.2) que desenha a projeção 2D de
um icosaedro, permite pintar cada uma das dez faces visíveis e transformá-la por
translação e escala. Trabalho da disciplina de Introdução à Computação Gráfica.

⚠️ **O código só pode usar os recursos que o professor ensinou.** Antes de
alterar qualquer coisa, leia [docs/restricoes-do-material.md](docs/restricoes-do-material.md).

## Executar

Abrir `Editor-Icosaedro.slnx` no Visual Studio e rodar. O executável fica em
`Projeto Isocaedro/bin/Debug/Projeto Isocaedro.exe`.
